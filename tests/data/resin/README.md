`chitubox_siraya_blu_50um.cfg` is a Chitubox resin profile from
https://github.com/Photonsters/CBD-based-printers-list (`phenom/chitubox-resin-profiles`, The Unlicense), used to test the
Chitubox profile importer.

`prusaslicer_anycubic_material.ini` is the first Anycubic material section of PrusaSlicer's `AnycubicSLA.ini` (version 2.9.6,
AGPL-3.0), used to test the PrusaSlicer material importer.
